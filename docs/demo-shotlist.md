# 45-second demo: GitBounty Court

## Visual direction

- 16:9, 1920×1080, 30 fps.
- Dark graphite interface, restrained electric-blue and warm amber accents.
- Fast but readable motion: cursor focus, card transitions, evidence highlights, verdict reveal.
- Use actual screen recordings for the deployed contract, GitHub PR, Arkhai escrow and finalized transaction. Do not fake explorer confirmations.
- Place the Internet Court, GenLayer and Arkhai logos in the opening and closing frames. Use official partner press-kit assets and follow their brand rules.

| 41–45s | Three logos + repository URL | “GitBounty Court. Escrow the work. Adjudicate the dispute.” |

## Capture checklist

- [ ] Arkhai escrow creation proof (real transaction)
- [ ] GitHub issue / PR and changed files
- [ ] GenLayer contract address and Bradbury transaction
- [ ] Finalized execution result and stored verdict
- [ ] Arkhai settlement proof, or clearly label operator settlement if no relay is deployed
- [ ] Three official logos: Internet Court, GenLayer, Arkhai
- [ ] Public GitHub repository URL

## Editing notes

Use a real screen recording as the source. Edit in a video tool with speed ramps, zooms, motion tracking, animated callouts, clean transitions, and readable captions. Keep each UI shot under 5 seconds unless the verdict needs more time. Avoid fake terminal output, fake transaction hashes, fabricated validator counts, or unverified claims.
